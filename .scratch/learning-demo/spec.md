# 첫 학습 데모

## 합의된 방향

- 제품 이름은 몰입 퀘스트이며 Rust + Dioxus로 Windows/macOS 앱을 개발한다.
- 첫 버전의 학습 언어는 Python만 지원한다. Java·Rust 등 다른 학습 언어는 후속 범위이며 앱 자체의 구현 언어는 Rust를 유지한다.
- 수업 콘텐츠는 별도 작성·추가가 가능해야 한다.
- 강사와 관리자 모두 수업·챕터·단원과 테스트 케이스를 작성할 수 있다. 수업은 공개 문제은행처럼 누구나 사용할 수 있도록 제공하며 다른 강사도 자신의 클래스룸에 배정할 수 있다. 초안·게시 절차는 아직 정하지 않았다.
- 첫 운영의 강사는 사용자 본인 한 명이다. 일반 가입 학생에게 클래스룸·수업 생성 권한을 부여하지 않는다. 강사 역할은 일반 가입자가 스스로 선택할 수 없으며 관리자 역할의 콘텐츠 작성 가능성은 기존 합의를 유지한다.
- 수업 수정은 작성자 본인만 가능하며 수업 복사 기능은 제공하지 않는다. 관리자가 타인의 수업 내용을 수정하는 예외 권한도 현재 합의 범위에 포함하지 않는다.
- 수업 수정은 기존 수업에 반영한다. 수정으로 별도의 새 수업을 생성하지 않는다. 단원 추가·삭제 시 기존 완료 기록은 유지하며 현재 단원 구성을 기준으로 진도율을 재계산한다. 삭제된 단원의 제출·테스트 기록은 학습 이력으로 보존하되 현재 진도 집계에서 제외한다.
- 단원 수정 시 작성자가 '다시 풀어야 하는 변경'인지 직접 표시한다. 문구 수정은 완료 상태를 유지하고 본질적인 변경은 해당 단원의 완료를 취소한다. 이전 제출·테스트 기록은 보존한다.
- 수업은 챕터, 챕터는 단원으로 구성된다.
- 강사는 클래스룸을 만들고 가입 링크로 로그인한 학생을 초대한다.
- 강사가 선택한 수업을 클래스룸에 배정하며 학생별 진도를 확인한다.
- 사용자 AI 도구 설치는 안내만 제공한다.
- Python·Java·Rust·ML·AI 등 수업의 학습 작업은 학생 개인 컴퓨터의 파일·도구·연산 자원을 사용하는 로컬 환경에서 수행한다. 모든 AI 호출이 오프라인이어야 한다고 확정한 것은 아니다.
- 코드 작성과 실행은 앱 내부에서 수행한다. 학생은 앱 안에서 로컬 학습 환경을 사용한다.
- 앱 내 AI는 설명·힌트 제공과 학생 코드의 직접 수정·실행을 모두 지원해야 한다. 연결 제공자별 기능 차이와 실제 도구 통합 방식은 구현 단계에서 다룬다.
- 단원 완료의 기본 기준은 학생이 작성한 프로그램에 대해 테스트 케이스를 실행하여 통과 여부를 확인하는 것이다. 현재 로컬 데모의 수동 완료 표시는 최종 완료 판정 방식이 아니다.
- 첫 버전의 기본 검사는 표준 입력을 넣고 표준 출력을 비교하는 입출력 테스트다. 수업 작성자가 입력값과 예상 출력값을 제공하며, Python 테스트 코드 작성 지원도 합의했으나 그 편집 형식은 아직 정하지 않았다.
- 앱과 실행 관리는 Rust로 구현한다. 기본 입출력 문제에는 입력·예상 출력 데이터를 사용하고, 복잡한 검사가 필요한 단원에는 수업 작성자가 Python 검사 코드를 붙일 수 있도록 한다. 검사 코드의 구체적인 작성 형식은 아직 정하지 않았다.
- 코드가 제공되고 학생이 지정된 빈칸만 수정하는 문제도 지원한다. 제공된 코드와 답안을 결합한 프로그램을 테스트하며 빈칸 표현 형식은 아직 결정하지 않았다.
- 테스트 실행은 학생 컴퓨터에서 이루어진다. 중앙 서버에는 학생별 단원 진도, 테스트 결과와 제출 시점의 코드를 저장하며 강사가 확인할 수 있다. 코드 편집 중의 전체 변경 이력이나 AI 대화 저장은 아직 합의하지 않았다.
- 서비스는 상시 인터넷 연결을 전제로 한다. 오프라인 학습과 연결 복구 후 지연 동기화는 제품 범위에 포함하지 않는다. 로컬 실행과 온라인 서비스 이용은 함께 이루어진다.
- 로컬 저장은 SQLite, 배포 서버 DB는 Supabase PostgreSQL을 고려한다.

## 이번 구현

로컬 샘플 클래스룸에서 파일 기반 수업을 학습하고 단원 완료 진도를 저장한다. 강사 미리보기는 이 컴퓨터의 샘플 학생만 표시한다.

## 후속 작업

- 로그인·역할과 클래스룸 생성
- 초대 링크 발급·가입 및 접근 권한
- 수업 목록·배정 관리
- 서버를 통한 학생 진도 동기화
- AI 도구 사용 안내 확장
- Windows/macOS 설치 패키지

## 구현 단계에서 구체화할 항목

- 앱 내부 터미널과 AI 도구의 구체적인 통합 방식
- 테스트 케이스 작성·배포·실행 방식과 통과 기록의 신뢰 수준
- 제출 기록 외 추가 학습 활동 기록의 범위
- 수업·문제·Python 검사 코드의 작성 형식
- 클래스룸 가입·권한·초대 링크 정책
- 온라인 학습 기록 전송과 저장 실패 표시
