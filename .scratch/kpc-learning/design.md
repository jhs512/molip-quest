# KPC 전용 몰입 학습 설계 인터뷰

진행 상태: grill-with-docs 완료. 아래 최종 결정 요약을 기준으로 to-spec → to-tickets → implement를 진행한다.

## 확정된 내용

- 대상: KPC 「머신러닝을 활용한 금융데이터 분석」 교재와 수업 전용. 범용 수업 플랫폼을 만들지 않는다.
- 일정: 3일, 8시간 + 8시간 + 4시간. 기존 교재의 교시 배분은 참고 자료이며 새 미션 배분은 아직 확정하지 않았다.
- Rust + Dioxus 설치형 앱. Windows와 macOS 대상.
- 앱에 AI 기능, 서비스 로그인, 중앙 서버, 인터넷 연결 요구를 두지 않는다.
- 콘텐츠: 챕터 → 단원 → 개념·코딩 문제·퀴즈. 단원 내 배치는 학습 흐름에 맞춘다.
- 개념은 설명 콘텐츠. 문제는 학생이 코드를 작성하여 푸는 코딩 실습.
- 퀴즈 하나에 여러 문항을 포함하며 객관식·주관식을 혼합할 수 있다. 10문항 또는 각 유형 10문항도 가능해야 한다.
- 게임 미션처럼 작은 목표와 클리어 피드백을 제공하고 점진적으로 성장하는 학습 경험을 만든다.
- 각 코딩 문제의 실행은 독립적이어야 한다. 앞 문제의 변수·파일·실행 결과에 의존하지 않는다.
- 필요한 설명·자료·코드 작성·실행·검사·피드백을 앱 안에서 제공한다. 별도 브라우저나 Notebook 작업을 요구하지 않는다.
- 최초 실행 환경은 앱 설치·실행 전에 GitHub README의 CLI 명령어를 따라 학생이 준비한다. macOS Homebrew 설치부터 Python·uv 준비까지 초보자 기준으로 안내한다. 인터넷은 이 사전 준비 단계에서 사용한다. 수업 패키지는 README에서 일괄 설치하지 않는다. 각 문제에서 필요한 패키지를 설치한다.
- 코드·답안·채점·진도 기록은 로컬에 보관한다.

## 추가로 확정된 내용

- 챕터는 공식 교재의 7개 주제로 구성한다. 일차·예상 시간은 챕터와 단원의 보조 정보로 표시한다.
- 미션은 앞 미션을 클리어해야 다음 미션이 해금된다.
- 각 코딩 문제에 정답을 얻기 위한 프롬프트 복사 버튼을 제공한다.
- 프롬프트에는 해당 문제 설명·입출력 또는 검사 조건·독립된 준비 자료 설명·기본 코드·학생의 현재 코드를 포함한다. 필요한 수정과 완성 코드를 요청한다.
- 복사한 프롬프트는 학생이 외부 AI에 직접 붙여넣는다. 앱 자체에는 AI 연결이나 AI 호출 기능을 추가하지 않는다. 응답 코드는 학생이 앱에 붙여넣어 실행·채점한다.
- 모든 코딩 문제는 학생이 main.py 파일 하나만 작성하여 해결한다. 여러 소스 파일의 생성·편집·관리를 요구하지 않는다.
- 정답 프롬프트에는 반드시 “설명 없이, 바로 실행할 수 있는 Python 파일 하나(main.py)의 전체 코드만 제공해 주세요”를 포함한다. 데이터는 앱이 준비하며 학생에게 추가 파일 작성을 요구하지 않는다.

- Jupyter Notebook을 사용하지 않는다. 코딩 작성·실행·채점은 앱의 단일 Python 파일 편집 화면에서 수행한다.
- 퀴즈 재도전은 틀린 문항만 반복한다. 이미 맞힌 문항은 다시 응답하도록 요구하지 않으며 문항별 완료를 로컬에 저장한다. 전체 문항을 누적하여 맞히면 퀴즈가 클리어된다.

- 주관식은 단답형으로 확정한다. 문항별 복수 인정 답안을 등록하여 한글·영문 표현과 약어를 정답으로 인정한다. 등록된 답안과 비교하며 띄어쓰기와 영문 대소문자를 정규화한다.

- 기본 도구(Python·uv 및 필요 시 Homebrew)는 README로 사전에 설치한다. 추가 Python 패키지는 문제별 설치 버튼으로 준비한다.
- 패키지 충돌과 실행 상태 공유를 방지하기 위해 문제별 환경을 분리하는 방식을 추천했다. 사용자의 확인은 아직 없으므로 확정으로 취급하지 않는다.
- 문제별 패키지 설치 때 인터넷 다운로드를 허용할지 확인 중이다. 학습 실행에는 인터넷을 요구하지 않는다.

## 이번 라운드에서 정할 사항

1. 챕터 배치: 공식 7주제로 확정.
2. 다음 미션 이동: 선행 미션 클리어 후 해금으로 확정. 완료한 미션의 복습·재도전은 후속 확인.
3. 퀴즈 클리어 기준: 모든 문항을 누적 정답 처리하면 완료. 재도전은 오답 문항만 대상으로 확정.
4. 주관식 유형: 단답형 및 한글·영문 복수 인정 답안으로 확정.
5. 의존성 준비: README에서 KPC 전용 환경과 전체 패키지를 한 번에 설치하는 것으로 최종 확정. 준비 단계의 인터넷은 허용하며 문제별 설치 버튼은 제외.
6. 웹 수집·Jupyter 항목: Jupyter를 쓰지 않고 앱 내 개념 및 저장 HTML·CSV 실습으로 변경하는 것으로 확정.

## 현재 구현 상태

단원 안의 개념·코딩·혼합 퀴즈 모델, 개념·퀴즈 화면, 미션별 진도 저장 구조를 작업 중이며 로컬 미커밋 상태다. 컴파일 확인은 했지만 KPC 교재 콘텐츠 배치와 검증은 미완료다. 이번 인터뷰의 결정을 반영하기 전까지 완료로 취급하지 않는다.

## 환경 준비 최종 결정

사용자는 이 앱을 확장하지 않는 3일짜리 고정 수업으로 사용할 예정이며, 문제별 설치 대신 한 번에 설치하는 방향을 제안했다.

추천: README에서 Python·uv 및 KPC 수업 전체에 필요한 고정 버전 패키지를 하나의 수업 전용 환경에 한 번에 설치한다. 패키지 준비 단계만 인터넷을 사용한다. 각 코딩 문제는 공유 환경의 Python을 사용하되, 새 프로세스와 별도 작업 폴더에서 실행한다. 환경 공유는 이전 문제의 변수·파일·코드 의존을 뜻하지 않는다. 문제 실행 독립성은 그대로 유지한다.

사용자가 이 방향에 동의했다. README에서 KPC 전용 환경과 전체 수업 패키지를 한 번에 설치하는 것으로 확정한다. 문제별 패키지 설치 버튼은 제공하지 않는다. 앞의 문제별 설치 논의는 변경 경위이며 최종 결정이 우선한다.

## 오프라인 수집 실습 결정

웹 수집과 주가 다운로드는 원리 학습을 목적으로 저장된 HTML·CSV를 사용한다. 앱의 학습 과정에서 실시간 사이트 접속이나 주가 다운로드를 요구하지 않는다. 필요한 자료는 앱이 준비하고 학생은 단일 Python 파일로 실습한다.

## 남은 확인

개념 콘텐츠의 완료 기준은 단답형 확인 문제 한 개를 맞히는 것으로 확정됐다. ‘이해했어요’ 버튼만으로 완료 처리하지 않는다. 코딩 문제는 검사 통과, 퀴즈는 모든 문항의 누적 정답으로 완료한다.

## 최종 결정 요약 — 이전 논의보다 우선

- 대상은 KPC 3일 수업(8+8+4시간) 전용이며 더 확장하는 범용 플랫폼은 만들지 않는다.
- 공식 7주제를 챕터로 구성하고, 챕터 안의 단원에 개념·코딩 문제·퀴즈를 학습 순서로 배치한다.
- 개념: 설명과 자체 단답형 확인 문항 **정확히 한 개**. 정답을 맞혀야 개념을 클리어한다.
- 코딩 문제: 학생은 main.py 하나만 편집한다. 준비 코드와 데이터는 문제 안에서 모두 제공하고, 새 프로세스와 별도 작업 폴더로 실행한다. 테스트를 통과하면 클리어한다.
- 퀴즈: 여러 객관식·주관식 단답형 문항을 혼합할 수 있다. 이미 맞힌 문항은 로컬에 저장하고 오답만 재도전한다. 모든 문항을 누적 정답 처리하면 클리어한다.
- 단답형은 한글·영문·약어 등 여러 인정 답안을 등록하고 대소문자·띄어쓰기 차이를 처리한다. 개념 확인 문항에도 같은 기준을 적용한다.
- 선행 미션을 클리어하면 다음 미션을 해금한다. 완료한 미션은 복습할 수 있으며 재도전 횟수 제한은 없다.
- 각 코딩 문제에 정답 프롬프트 복사 버튼을 둔다. 설명·검사 조건·기본 코드·현재 코드·필요 자료 설명을 포함하고 ‘설명 없이 바로 실행 가능한 Python 파일 하나(main.py)의 전체 코드만 달라’고 요청한다. 학생이 외부 AI에 직접 붙여넣으며 앱은 AI를 호출하지 않는다.
- 개념 읽기부터 답안 작성·실행·채점·오답 피드백까지 앱 안에서 제공하고 Jupyter Notebook을 쓰지 않는다.
- README에서 Homebrew 등 필요한 기본 도구와 Python·uv·KPC 전체 수업 패키지를 하나의 고정된 수업 환경에 한 번에 준비한다. 설치 준비 때만 인터넷을 쓰며 문제별 설치 버튼은 제공하지 않는다.
- 학습은 오프라인. 웹 수집은 저장 HTML, 주가 분석은 저장 CSV 등 앱이 준비한 자료로 원리를 배운다.
- 서비스 로그인·AI 연결·중앙 서버를 두지 않는다. 학생 코드·답안·채점·진도는 로컬에 저장한다.

설계 인터뷰의 추가 질문은 없다. 개념 확인, 퀴즈 누적 정답, 순차 해금, 정답 프롬프트 복사, 독립 실행과 KPC 교재 재구성을 이후 명세와 티켓의 검증 대상으로 삼는다. 구현과 자동 검증을 완료했다. 마지막 코드 리뷰 결과와 전달 상태는 review.md에 기록한다.
