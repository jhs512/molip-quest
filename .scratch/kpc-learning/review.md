## Standards

문서화된 규칙 위반이나 차단 문제는 없다. 로컬 명세·티켓 위치와 도메인 용어는 저장소 지침을 따른다.

선택적 개선 제안 두 개:
- src/curriculum.rs: 코딩 문제 검증 시 전체 수업 복사와 JSON 파서 재진입 대신 공통 단원 검증 경계를 추출할 수 있다. 가능한 Message Chains / Feature Envy이며 기능 결함은 아니다.
- src/ui.rs: 완료 미션 조회를 위해 작은 임시 Course를 만드는 대신 저장 계층에 단원별 조회 경계를 둘 수 있다. 가능한 Feature Envy이며 기능 결함은 아니다.

고정 KPC 과정의 현재 동작에는 영향을 주지 않아 이후 유지보수 제안으로 남긴다.

## Spec

발견 1건, 수정 완료: 성별 생존율 막대그래프 검사에서 첫 막대만 검사하여 순서가 반대인 정답을 거부하고 잘못된 남성 값을 허용했다. 이제 성별 tick label에 대응하는 두 막대 높이와 축을 검사한다. 역순 정답 통과·남성 생존율 0 오답 실패 회귀 테스트를 추가했다. 명세 리뷰 담당이 실제 Python 검사로 수정 결과를 재확인했다.

그 외 개념 확인, 한·영 복수 답안, 누적 퀴즈 및 재시작, 순차 해금, 독립 실행과 원본 데이터 복원에서 미해결 요구사항 누락·범위 확장은 없다.

규칙: 위반 0, 선택적 개선 2. 명세: 발견 1, 해결 1, 미해결 0.
