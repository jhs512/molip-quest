# KPC 전용 몰입 학습

Status: ready-for-agent

## Problem Statement

3일(8+8+4시간) KPC 금융 데이터·머신러닝 수업의 초보 수강생은 긴 교재, Notebook의 선행 셀, 여러 파일과 환경 준비에 막힌다. 현재 앱의 Python 예제만으로는 교재의 개념·실습·이해 확인을 게임 미션처럼 이어갈 수 없다.

## Solution

공식 7주제 챕터를 단원과 작은 미션으로 구성한다. 개념마다 단답형 확인 문제 한 개, 독립된 단일 Python 파일 코딩 실습, 객관식·단답형 혼합 퀴즈를 앱 안에서 제공한다. 순차 해금과 누적 정답, 오답 재도전, 즉시 피드백으로 진행한다. README에서 전체 환경을 한 번에 준비하고 학습은 로컬에서 수행한다.

## User Stories

1. KPC 수강생으로서 공식 7주제의 챕터를 보고 싶다. 3일 수업의 위치를 알 수 있도록.
2. 수강생으로서 단원별 개념·코딩·퀴즈 순서를 따라가고 싶다. 작은 미션으로 성장하도록.
3. 수강생으로서 개념 설명과 예제를 읽고 싶다. 앱 밖 자료 없이 이해하도록.
4. 수강생으로서 개념마다 단답형 문항 한 개를 풀고 싶다. 이해를 확인하도록.
5. 수강생으로서 한글·영문·약어 등 인정 답안으로 답하고 싶다. 표현 차이로 오답이 되지 않도록.
6. 수강생으로서 영문 대소문자와 띄어쓰기 차이를 허용받고 싶다. 지식을 평가하도록.
7. 수강생으로서 main.py 하나만 작성하고 싶다. 여러 파일 관리에 막히지 않도록.
8. 수강생으로서 문제 안에 필요한 준비 코드와 데이터가 있기를 원한다. 앞 문제 실행에 기대지 않도록.
9. 수강생으로서 코드를 실행하고 표·그래프·오류를 보고 싶다. 결과를 이해하도록.
10. 수강생으로서 자동 검사를 통과해 코딩 미션을 완료하고 싶다. 결과를 즉시 확인하도록.
11. 수강생으로서 문제의 정답 요청 프롬프트를 복사하고 싶다. 원하는 외부 AI에서 도움을 얻도록.
12. 수강생으로서 설명 없이 한 Python 파일로 답을 요청하고 싶다. 받은 코드를 바로 붙여넣도록.
13. 수강생으로서 여러 객관식·단답형이 섞인 퀴즈를 풀고 싶다. 이해를 종합 확인하도록.
14. 수강생으로서 맞힌 문항은 유지하고 오답만 다시 풀고 싶다. 불필요한 반복을 피하도록.
15. 수강생으로서 퀴즈 해설과 인정 답안을 보고 싶다. 틀린 이유를 이해하도록.
16. 수강생으로서 모든 문항을 누적해 맞히면 퀴즈를 완료하고 싶다. 포기하지 않고 도전하도록.
17. 수강생으로서 앞 미션을 완료하면 다음 미션이 열리기를 원한다. 학습 순서를 따라가도록.
18. 수강생으로서 완료한 미션을 다시 보고 싶다. 복습하도록.
19. 수강생으로서 앱 재시작 후 코드·답안·진도가 유지되기를 원한다. 학습을 이어가도록.
20. 수강생으로서 자료·Python 실행·채점이 인터넷 없이 동작하기를 원한다. 연결 때문에 막히지 않도록.
21. 수강생으로서 README의 macOS·Windows 명령어로 환경을 한 번에 준비하고 싶다. 처음 설치를 쉽게 하도록.
22. 수강생으로서 환경 진단을 받고 싶다. 준비가 부족하면 해결할 위치를 알도록.
23. 강사로서 교재의 실제 학습 주제를 미션으로 제공하고 싶다. 8+8+4시간을 의미 있게 사용하도록.
24. 강사로서 모든 코딩 문제가 새 상태에서 실행 검증되기를 원한다. 학생의 실행 순서와 무관하게 동작하도록.

## Implementation Decisions

- 기존 콘텐츠 모델·Python 실행기·로컬 저장소·편집기·표/그래프 출력을 확장한다.
- 단원 안에 순서가 있는 개념·코딩·퀴즈 미션을 둔다. 개념은 단답형 문항 정확히 한 개를 포함한다.
- 완료 조건: 개념 문항 정답, 코딩 검사 통과, 퀴즈 전체 문항 누적 정답. 단원의 전체 미션 완료 시 단원 완료.
- 문항별 성공 상태와 답안·실행 검사 기록은 로컬에 저장하고 재시작 후 유지한다. 이전 정답을 재채점하거나 오답으로 바꾸지 않는다.
- 단답형은 복수 인정 답안과 공백·영문 대소문자 정규화로 채점한다. 문항 해설을 제공한다.
- 순서상 첫 미완료 미션까지 접근하고 완료 미션은 복습할 수 있다. 챕터·단원·미션 진도를 표시한다.
- KPC 실제 교재를 출처로 콘텐츠를 직접 재구성하고 필요한 데이터·저장 HTML을 앱에 포함한다. 실시간 웹 수집이나 다운로드를 요구하지 않는다.
- 학생은 하나의 Python 소스만 편집한다. 각 실습은 필요한 import·준비 코드를 자체 제공하고, 매 실행마다 새 프로세스·작업 폴더·원본 데이터로 시작한다.
- 정답 프롬프트는 문제 조건·준비 코드·현재 코드와 데이터 설명을 포함하며 설명 없는 단일 Python 파일 답안을 요청한다. 클립보드 복사만 수행하며 앱의 AI 호출 기능은 없다.
- 3일 고정 과정 전체 패키지를 수업 전용 환경에 한 번에 설치한다. 설치 다운로드만 인터넷을 사용한다.
- 기존 형식의 로컬 기록과 샘플 테스트는 보존하되 기본 학습 화면은 KPC 과정으로 바꾼다.

## Testing Decisions

- 공개 경계에서 콘텐츠 불러오기 → 학습 답안/실제 Python 실행 → 로컬 결과 저장 → 진도·해금 상태를 검증한다. 내부 DB 구현에 결합하지 않는다.
- 개념 단답 정규화·누적 퀴즈·재시작·순차 해금·문항 20개 혼합 처리를 검증한다.
- 실제 Python으로 모든 제공 코딩 문제의 참조 답안이 독립 실행 및 검사 통과함을 검증한다. 대표 오답도 통과하지 않아야 한다.
- 프롬프트에는 해당 문제의 정보와 단일 파일 요청이 포함되고 AI 키·접속이 필요 없음을 검증한다.
- 기존 실행 오류·사용자 검사·표/그래프·로컬 진도 통합 테스트를 유지한다. Windows 빌드와 앱 실행을 확인한다.
- macOS 실제 실행은 현재 Windows 호스트에서 확인할 수 없으므로 미검증으로 명시한다.
- 사용자가 추가 질문 없이 세 스킬 연속 실행을 요청했으므로 검증 경계와 티켓 크기 확인은 생략한다.

## Out of Scope

범용 수업 플랫폼, 수업 작성/공유 서버, 로그인, AI 내장·자동 호출, Jupyter Notebook, 실시간 금융 데이터/사이트 수집, 여러 소스 파일 편집, 긴 서술형 AI 채점, KPC 이외의 언어·수업 확장.

## Further Notes

기존 교재의 공식 7주제·20시간을 유지하면서 저장 자료로 원리 실습을 재구성한다. 교재 폴더는 읽기만 하며 수강생 명단을 사용하지 않는다. 구현 리뷰는 이번 변경 시작 전 커밋 d059eed를 고정 기준으로 두 축에서 수행한다.
