# 실행 입력과 제출 흐름

Status: completed

이 기록은 정답 후 현재 미션에 머무르던 이전 UI 결정을 대체한다.

- 코드 실행은 첫 입출력 예제를 기본 입력으로 제공하고 입력칸을 펼친다. 학생이 값을 바꿔 연습할 수 있다. 실행 성공은 채점 완료와 구분한다.
- 입력이 부족하여 EOFError가 나면 실행 입력을 확인하라는 안내를 제공한다.
- 개념·퀴즈·코딩 버튼을 제출로 통일한다. 전체 검사를 통과하면 완료를 저장하고 다음 미션으로 자동 이동한다. 단원을 끝내면 다음 단원으로 넘어간다. 정답 팝업은 계속 제공한다.
- 오답 제출은 현재 미션에 남고 다음 미션을 해금하지 않는다.

실제 WebView2 검증: 10000 3 기본 입력으로 30000 출력, 입력칸 표시, 코드 실행만으로는 완료하지 않음, 오답 제출 유지, 정답 제출 자동 이동, 단원 경계 이동과 이전 복습을 확인했다. Markdown·CodeMirror 검증도 통과했다. Windows 빌드 및 cargo fmt --check 통과.
