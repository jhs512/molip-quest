# 학습 화면과 단원 구성 개선

Status: completed

## 변경

- 개념·퀴즈·코딩 검사 통과 후 정답입니다 팝업을 보여준다. 확인을 눌러도 현재 미션에 머무르며 다음 버튼으로 이동한다.
- 이전·다음은 해금된 미션 사이와 단원 경계를 모두 이동한다. 미완료 선행 미션을 건너뛰는 이동은 계속 막는다.
- 실제 CodeMirror 6 콘텐츠와 편집 코드 동기화를 확인했다.
- 설명·문항·선택지·해설은 Markdown을 렌더링한다. 제목·강조·인라인 코드·표·인용문과 Python 코드 블록 색상을 제공한다. Lezer를 기존 로컬 편집기 번들에서 재사용해 CDN 없이 표시한다.
- 단원의 활동 배열은 유형 순환을 강제하지 않는다. 첫 실행과 전처리 단원은 개념을 반복하고, 그림 해석·신용 지표 단원은 별도 개념 활동 없이 문제 안에 설명을 제공한다. 최종 회귀 단원은 중간 확인 퀴즈를 추가했다.
- 현재 7챕터·20단원·75미션·34코딩 문제. 본질적으로 순서를 변경한 5개 단원은 revision 2로 새 구성을 확인하게 했다. 과거 제출 기록은 보존한다.

## 검증

- cargo fmt --check, cargo build --locked --bin molip-quest
- cargo test --locked: 17개 통과. 34개 참조 답안의 독립 실행 포함.
- tools/verify-learning-flow.py: 실제 WebView2에서 Markdown 코드 토큰·강조, 정답 팝업, 현재 미션 유지, CodeMirror, 개념과 문제 사이 왕복, 단원 사이 왕복 통과.
- tools/verify-ime.py: 합성 한글 조합 입력 유지, 값 재쓰기 0회, 답안 복원·채점·정답 팝업·다음 이동 통과. Windows 실제 IME 타이핑을 대신한다고 주장하지 않는다.
- UI 검증은 고유 course id의 테스트용 파일로 수행해 학생의 진도와 분리했다.
