# 06: 입출력 테스트와 중앙 제출·완료 기록

**What to build:** 작성자가 입력·예상 출력 테스트를 제공하면 학생이 실행하고 제출 코드·테스트 결과·완료 상태를 중앙에 기록한다.

**Blocked by:** 05: 앱 내부 Python 작성과 로컬 실행.

**Status:** ready-for-agent

- [ ] 작성자가 단원의 입력값과 예상 출력값을 저장하고 학생이 검사할 수 있다.
- [ ] 실제 로컬 Python 실행으로 통과·오답·실행 실패를 구분한다.
- [ ] 통과 결과와 제출 시점 코드가 학생·클래스룸·수업·단원에 대응하여 중앙에 저장된다.
- [ ] 서버 저장 성공 여부를 표시하고 실패를 성공한 제출로 표시하지 않는다.
- [ ] 단원 완료는 테스트 통과를 기준으로 하며 수동 완료 버튼을 제거한다.
- [ ] 반복 요청과 중복 제출로 완료 수가 증가하지 않으며 수업·챕터 진도를 볼 수 있다.
- [ ] 표준 출력 비교 규칙과 종료 실패 처리를 명시하고 경계 사례를 검증한다.
