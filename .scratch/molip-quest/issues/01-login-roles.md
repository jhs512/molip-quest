# 01: 로그인과 역할에 따른 앱 진입

**What to build:** 사용자가 앱에서 로그인·로그아웃하고 학생 또는 지정된 강사·관리자 역할에 맞는 화면으로 진입한다.

**Blocked by:** None (can start immediately).

**Status:** ready-for-agent

- [ ] 학생 계정이 자신의 학습 화면으로 진입하고 로그아웃할 수 있다.
- [ ] 초기 강사는 지정된 사용자 한 명이며 일반 가입자가 강사 권한을 선택할 수 없다.
- [ ] 앱과 서버 모두 역할을 검사하며 학생의 강사 전용 요청을 거부한다.
- [ ] Rust 서버와 개발 저장소에서 동작을 확인하고 배포 PostgreSQL 저장 경계에서도 같은 역할 동작을 검증한다.



## Comments

2026-10-02: Rust 서버와 Dioxus 화면에 기능을 구현했습니다. 공통 학습·중앙 제출 흐름 및 관련 자동 검증은 통과했습니다. 실제 Windows 창을 실행했습니다. macOS 및 배포 환경 검증은 티켓 13에서 별도로 추적하며 각 항목의 전 플랫폼 통과를 의미하지 않습니다.
