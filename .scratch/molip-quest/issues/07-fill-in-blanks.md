# 07: 지정 빈칸 문제 작성·풀이·검사

**What to build:** 작성자가 코드 템플릿의 빈칸을 지정하고 학생은 빈칸만 채워 합성된 프로그램을 검사·제출한다.

**Blocked by:** 06: 입출력 테스트와 중앙 제출·완료 기록.

**Status:** ready-for-agent

- [ ] 작성자가 템플릿과 수정 가능한 영역을 정의할 수 있다.
- [ ] 학생은 지정된 영역만 수정하며 고정 코드는 변경할 수 없다.
- [ ] 합성된 전체 코드를 입출력 검사하고 중앙에 제출한다.
- [ ] 잘못된 빈칸 설정과 고정 영역 변경을 거부한다.
