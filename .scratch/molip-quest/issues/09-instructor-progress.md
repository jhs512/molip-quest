# 09: 강사의 학생 진도와 제출물 확인

**What to build:** 강사가 클래스룸에서 학생별·수업별 진도와 제출 코드·테스트 결과를 확인한다.

**Blocked by:** 06: 입출력 테스트와 중앙 제출·완료 기록.

**Status:** ready-for-agent

- [ ] 강사가 중앙 저장된 학생별 완료 단원 수와 진도율을 확인한다.
- [ ] 단원을 선택해 제출 시점 코드와 테스트 결과를 확인한다.
- [ ] 다른 클래스룸의 학생 기록을 열람할 수 없다.
- [ ] 로컬 테스트 결과를 서버 재검증 성적으로 표현하지 않는다.
- [ ] 학생 제출부터 강사 확인까지 대표 전체 흐름을 검증한다.
