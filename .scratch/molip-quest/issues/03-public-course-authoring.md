# 03: 공개 수업 작성과 수업 은행 조회

**What to build:** 강사·관리자가 수업·챕터·단원을 작성하고 공개 수업 은행에서 조회한다.

**Blocked by:** 01: 로그인과 역할에 따른 앱 진입.

**Status:** ready-for-agent

- [ ] 작성자가 제목·설명·챕터·단원을 순서대로 작성하고 다시 열 수 있다.
- [ ] 앱 재빌드 없이 작성된 수업을 수업 은행에서 확인할 수 있다.
- [ ] 수업은 작성자에게 귀속되며 학생은 작성할 수 없고 타인은 수정할 수 없다.
- [ ] 수업 복사 기능과 수정 시 새 수업 자동 생성은 제공하지 않는다.
- [ ] 빈 수업이나 중복 단원 식별자 등 잘못된 콘텐츠는 이해할 수 있는 오류로 거부한다.
