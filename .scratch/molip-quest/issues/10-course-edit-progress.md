# 10: 같은 수업 수정과 완료 기록 처리

**What to build:** 작성자가 같은 수업을 수정하고 단원 추가·삭제·본질 변경 규칙에 따라 학생의 진도와 과거 제출을 관리한다.

**Blocked by:** 06: 입출력 테스트와 중앙 제출·완료 기록.

**Status:** ready-for-agent

- [ ] 수정 후 같은 수업 식별자와 기존 클래스룸 배정을 유지한다.
- [ ] 단원 추가·삭제는 기존 완료 기록을 보존하고 현재 단원으로 진도율을 재계산한다.
- [ ] 삭제된 단원의 과거 제출·결과는 이력으로 보존하며 현재 진도 집계에서 제외한다.
- [ ] 문구 수정은 완료를 유지하고 작성자가 다시 풀어야 하는 변경으로 표시하면 해당 단원 완료를 취소한다.
- [ ] 이전 제출을 보존하고 변경 전 결과가 늦게 도착해 변경 후 완료를 회복하지 못하게 한다.
- [ ] 다른 작성자의 변경 요청은 거부한다.
