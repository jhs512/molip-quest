# 05: 앱 내부 Python 작성과 로컬 실행

**What to build:** 학생이 단원에서 Python 코드를 작성하고 자기 컴퓨터에서 실행하여 입력·출력·오류를 앱에서 확인한다.

**Blocked by:** 04: 클래스룸 수업 배정과 학생 목차.

**Status:** ready-for-agent

- [ ] 앱 안의 편집기에서 단원 코드를 작성하고 초안을 다시 열 수 있다.
- [ ] 입력을 제공하고 실제 Python 프로그램의 출력·오류·종료 상태를 확인한다.
- [ ] 실행은 학생 컴퓨터에서 이루어지며 중앙 서버에서 코드를 실행하지 않는다.
- [ ] Python 환경 미준비, 실행 오류, 시간 초과를 구분하고 실행량 제한을 둔다.
