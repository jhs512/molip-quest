# 04: 클래스룸 수업 배정과 학생 목차

**What to build:** 강사가 공개 수업을 클래스룸에 배정하면 소속 학생이 수업·챕터·단원 목차를 탐색한다.

**Blocked by:** 02: 클래스룸 생성과 가입 링크 참여; 03: 공개 수업 작성과 수업 은행 조회.

**Status:** ready-for-agent

- [ ] 강사가 공개 수업을 선택해 클래스룸에 배정할 수 있다.
- [ ] 학생은 참여한 클래스룸의 배정 수업과 목차를 볼 수 있다.
- [ ] 같은 공개 수업을 여러 클래스룸에 배정할 수 있다.
- [ ] 수업과 클래스룸의 배정 관계를 유지하며 배정 중복을 처리한다.
