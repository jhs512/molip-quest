# 02: 클래스룸 생성과 가입 링크 참여

**What to build:** 강사가 클래스룸과 가입 링크를 만들고 로그인한 학생이 링크로 참여한다.

**Blocked by:** 01: 로그인과 역할에 따른 앱 진입.

**Status:** ready-for-agent

- [ ] 강사가 클래스룸을 만들고 가입 링크를 확인할 수 있다.
- [ ] 학생이 로그인 전 링크를 열어도 로그인 후 대상 클래스룸 참여를 이어간다.
- [ ] 반복 가입은 중복 학생을 만들지 않는다.
- [ ] 강사는 자신의 클래스룸의 참여 학생을 확인하며 비참여자는 해당 기록에 접근할 수 없다.
