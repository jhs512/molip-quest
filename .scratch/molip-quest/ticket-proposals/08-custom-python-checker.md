# 08: 작성자 정의 Python 검사

**What to build:** 입출력 비교만으로 부족한 단원에 작성자가 Python 검사 코드를 제공하고 학생이 결과를 확인·제출한다.

**Blocked by:** 06: 입출력 테스트와 중앙 제출·완료 기록.

**Status:** draft

- [ ] 작성자가 Python 검사 코드를 저장하고 해당 단원에서 선택할 수 있다.
- [ ] 검사 입력과 학생 프로그램·산출물 접근 및 검사 결과 반환 계약을 문서화한다.
- [ ] 검사 실행은 학생 컴퓨터에서 수행하고 실패·검사 자체 오류·시간 초과를 구분한다.
- [ ] 검사 결과와 제출물이 중앙 기록·단원 완료 흐름에 연결된다.
- [ ] 간단한 입출력 문제는 검사 코드를 작성하지 않고 계속 사용할 수 있다.
