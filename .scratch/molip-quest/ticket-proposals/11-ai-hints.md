# 11: 사용자 AI 연결과 앱 내 설명·힌트

**What to build:** 학생이 준비한 AI 도구를 연결하고 앱 안에서 단원과 코드에 대한 설명·힌트를 받는다.

**Blocked by:** 05: 앱 내부 Python 작성과 로컬 실행.

**Status:** draft

- [ ] 사용자 AI 도구 준비·연결 안내를 제공하며 자동 설치하지 않는다.
- [ ] 최소 한 개 실제 연결을 구현하고 지원 대상을 명시한다.
- [ ] 앱 안에서 질문과 응답을 보고 단원·코드 맥락을 사용할 수 있다.
- [ ] 연결 실패와 사용 권한·한도 문제를 알기 쉬운 상태로 표시한다.
- [ ] 운영자 공용 AI 자격 증명이나 비용 부담 구조를 기본으로 사용하지 않는다.
- [ ] 대체 연결로 UI 동작을 검증하고 실제 지원 도구 연동은 별도로 확인한다.
