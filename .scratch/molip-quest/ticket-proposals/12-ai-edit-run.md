# 12: AI 코드 수정·실행과 학습 연동

**What to build:** 앱 안의 연결된 AI가 학생 코드를 수정하고 로컬에서 실행할 수 있으며 학생이 결과를 확인한다.

**Blocked by:** 07: 지정 빈칸 문제 작성·풀이·검사; 11: 사용자 AI 연결과 앱 내 설명·힌트.

**Status:** draft

- [ ] AI 코드 변경이 앱 편집기에 반영되고 실행 결과를 앱에서 볼 수 있다.
- [ ] 빈칸 문제에서는 AI도 고정 영역을 변경할 수 없다.
- [ ] AI 실행은 학습 작업 공간과 로컬 실행 관리 흐름을 사용한다.
- [ ] 변경된 코드는 기존 검사·제출 경로로 평가하며 AI의 완료 주장만으로 완료 처리하지 않는다.
- [ ] 설명·힌트 기능을 함께 유지하며 지원 도구별 기능 차이를 표시한다.
