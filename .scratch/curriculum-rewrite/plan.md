Status: 완료 (2026-10-03). 20개 단원 전부 다시 썼고 빌더를 `tools/kpc_course/`로 분리했다. 결과: 139 미션(개념 24 · 코딩 93 · 퀴즈 문항 124), 객관식 정답 위치 분산, 기존 90개 검사·참조 답안은 코드 변경 없이 유지. 2일차 8교시는 설계 요구대로 개념 없는 단원으로 두었고, 마무리는 코딩 `final-report` + 퀴즈 `course-wrap`으로 넣었다.

## 1. 스캔 결과 — 지금 무엇이 걸리는가

132개 미션을 학생 순서대로 전부 읽었다. 문제는 네 묶음이다.

### A. 문체가 "요약 노트"다
- 기존 개념 본문은 세 단락에 사실을 빽빽이 나열한다. "~입니다. ~합니다." 한 줄짜리 문장이 10개씩 이어지고, **왜** 그런지보다 **무엇**인지만 적는다. 예: `fit-train` 개념은 train_test_split 인자 3개, 훈련 1047/테스트 262, Pipeline, SimpleImputer, OneHotEncoder, "테스트에 fit하지 마세요"를 12문장에 담는다.
- 자동 백틱(`prose()`) 때문에 코드가 쪼개져 보인다: `groupby`('`sex`')['`survived`'], `index`=`False`, `ax.`bar`(...)`. 퀴즈 정답 표시까지 깨져 있다.
- 영어 용어를 설명 없이 던진다: Figure/Axes, Target, leakage, baseline, One-hot. 고등학생이 처음 보면 단어부터 막힌다.
- 수강생과 상관없는 메타 정보가 섞여 있다: uv·Anaconda·Jupyter, "OS마다 한글 폰트", yfinance·FinanceDataReader, "다른 Titanic 예제의 891행을 쓰지 마세요", Selenium 퀴즈.

## 2. 원칙 — 다시 쓸 때 지킬 것

1. **한 단원 = 한 이야기.** 개념은 "지난 시간에 ~했다 → 그런데 ~가 안 된다 → 그래서 오늘 ~를 배운다"로 시작한다. 코딩 미션은 그 이야기의 다음 장면이다.
2. **고등학생 기준.** 새 단어는 처음 나올 때 한국어로 풀고 괄호에 영어를 적는다: 정확도(accuracy). 비유를 하나씩 둔다(훈련/테스트 = 문제집/모의고사, 결측 = 설문지 빈칸, 누수 = 시험지에 답이 적혀 있는 것).
3. **왜를 먼저, 무엇을 그 다음.** 함수 이름보다 "이 숫자를 왜 알아야 하나"가 먼저.
4. **답을 미리 말하지 않는다.** 학생이 코드로 발견할 수는 개념에 쓰지 않는다. 검사는 그대로 유지.
5. **글 쓰는 사람의 문장으로.** 끝없이 반복되는 "~세요/~입니다" 대신 설명문 리듬. 한 문단 3~4문장, 개념 하나당 문단 3~4개 + 코드 예시 1개.
6. **자동 백틱 폐지.** 모든 텍스트를 손으로 쓴 Markdown으로(이미 새 미션은 그렇게 작성). 코드 조각은 통째로 백틱.
7. **문제 문구 틀:** 한 줄 맥락 → 할 일(2~3문장) → 확인 포인트("~이면 맞게 한 것"). 힌트는 지금 수준 유지(대체로 좋음).
8. **퀴즈:** 정답 위치 섞기(빌더에서 고정 시드로 셔플). 틀린 보기는 흔한 오해에서 가져온다. 해설은 "왜 다른 보기가 아닌가"까지. 수업 밖 지식 문항 삭제.
9. **챕터·단원 20개는 그대로.** 미션은 더하거나 합칠 수 있다.

## 4. 작업 방식

1. **빌더 구조 변경**: `tools/build-kpc-course.py`의 거대한 한 줄 호출을 단원별 파일 `tools/kpc_units/d1_p1_environment.py` … 20개로 분리. 각 파일은 여러 줄 문자열로 글을 쓴다. `prose()` 폐지. 검사·참조 답안은 기존 것을 그대로 옮긴다.
2. **퀴즈 정답 셔플**: `choice()`가 고정 시드로 보기를 섞고 `correct`를 따라 옮김. 해설은 보기 번호를 쓰지 않도록.
3. **자동 검사 추가** (빌드 시 실패하면 생성 중단):
   - 참조 답안 90+개 독립 실행 통과(기존 테스트)
   - 백틱 깨짐 패턴(`` `x`(`y`) ``) 0건
   - 객관식 정답 위치가 한쪽에 60% 이상 쏠리면 실패
