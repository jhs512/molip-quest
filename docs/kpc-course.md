## 설계 기준

개념에는 단답형 확인 문항을 정확히 한 개 포함합니다. 단원마다 각 유형의 수와 순서를 다르게 구성합니다. 개념과 문제를 번갈아 배치하거나, 별도 개념 미션 없이 여러 문제를 풀거나, 중간에 퀴즈를 넣을 수 있습니다. 개념이 없는 문제에는 풀이에 필요한 설명을 문제 본문에 제공합니다. 맞힌 퀴즈 문항은 저장되며 오답만 재도전합니다. 모든 문항이 누적 정답이면 다음 미션이 해금됩니다.

## 원고와 조정

원고 출처는 C:/works/kpc-lec/pages/periods/의 교시별 자료와 해당 프로젝트의 공식 7단원 안내입니다. 원본 프로젝트는 읽기만 했습니다. Notebook의 선행 셀을 요구하는 준비 코드는 각 문제의 main.py에 다시 포함했습니다. Jupyter 조작·실시간 웹 접근·주가 다운로드는 앱 사용 설명과 저장 자료 실습으로 바꿨습니다. 학생 명단은 사용하지 않았습니다.

콘텐츠는 `tools/kpc_course/` 안에 단원마다 한 파일(`d1_p1_environment.py` …)로 두고 `tools/build-kpc-course.py`가 `courses/kpc-finance.json`·`kpc-solutions.json`과 위 표를 생성합니다. 글은 전부 손으로 쓴 Markdown이며 자동 서식은 없습니다. 객관식 보기는 퀴즈 ID를 시드로 섞어 정답 위치가 고정되지 않습니다. 빌드 시 편집 검사(백틱으로 쪼개진 코드, 수업 밖 도구 이름, 개념 본문 길이와 코드 예시, 정답 위치 쏠림)에 걸리면 생성이 중단됩니다. 문체 기준은 한 단원을 하나의 이야기로 잇고, 새 용어는 한국어로 먼저 풀어 괄호에 영어를 적으며, 학생이 코드로 발견할 숫자는 개념에서 미리 말하지 않는 것입니다. 개념 11곳에는 강사·민지·준호·파이썬·빵 공장장·콜센터 팀장이라는 고정 등장인물의 2~3컷 만화를 `comic-gen` 펜스로 넣어 핵심 비유를 대화로 보여 줍니다(`assets/comics/README.md`). 만화는 빈 줄 없는 한 문단으로 쓰고 대사 한 줄은 두 행 안에 들어가게 합니다.

## 검증

모든 코딩 참조 답안은 새 프로세스·작업 폴더에서 독립 실행하여 검사합니다. 시각화는 실제 Figure·Axes의 데이터와 축을 검사하고, 모델링은 기준 비교와 자료 분리를 확인합니다. 고정된 승자나 높은 성능을 요구하지 않습니다.

코딩 미션은 하나의 목표와 결과를 중심으로 나눕니다. 종목별 금액 계산, 전체 금액 합산, 표 생성은 별도 미션이며, 각 미션은 자체 준비 코드를 제공합니다. 단원의 코딩 미션 수에는 고정 제한이 없습니다.
