# 몰입 퀘스트

사용자의 AI 도구와 함께 학습하고, 클래스룸에서 진도를 관리하는 설치형 튜토리얼 앱입니다.

## 프로젝트 방향

- Dioxus를 사용해 Windows와 macOS용 앱을 개발합니다.
- 수업은 앱과 분리하여 작성하고 추가할 수 있도록 설계합니다.
- 사용자가 원하는 AI 도구를 직접 설치하고 연결하도록 안내합니다.
- 필요한 경우 OmniRoute 설정을 안내합니다.
- 교사는 클래스룸에서 학생의 가입, 진도와 과제 제출 상태를 확인합니다.
- AI 사용은 사용자의 환경에서 이루어지며, 가입과 학습 기록은 서버에서 관리하는 구상을 검토합니다.

## 현재 상태

개발 워크플로 설정을 완료했습니다. 앱 구현과 수업 형식, AI 도구 연동 방식은 아직 확정하지 않았습니다.
