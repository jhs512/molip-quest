INSTALLATION

몰입 퀘스트 받는 법

운영체제에 맞게 앱과 학습 환경을 준비하세요.
아나콘다·Jupyter Notebook을 별도로 설치할 필요는 없습니다.

Windows 노트북PowerShell
  1. Windows 설치 파일 다운로드 ↗ 후 실행하세요.
  2. 시작 메뉴에서 PowerShell을 찾아 열고, 아래 명령으로 uv를 설치하세요.
    powershell -ExecutionPolicy Bypass -c "irm https://astral.sh/uv/install.ps1 | iex"
  3. PowerShell을 닫고 다시 연 뒤, 아래 명령을 한 번에 붙여 넣으세요. 수업에 필요한 Python과 패키지를 모두 준비합니다.
    $learningEnv = Join-Path $env:LOCALAPPDATA 'MolipQuest/MolipQuest/data/ml-env'
uv python install 3.13
uv venv "$learningEnv" --python 3.13
uv pip install --python "$learningEnv/Scripts/python.exe" -r https://raw.githubusercontent.com/jhs512/molip-quest/main/requirements-learning.txt
  4. 시작 메뉴에서 몰입 퀘스트를 열고 「환경 진단」을 확인하세요. 앱은 위에서 준비한 환경을 자동으로 사용합니다.

설치 파일은 아직 인증서로 서명되지 않았습니다. Windows에서 경고가 나오면 파일 출처를 확인하세요. WebView2가 없다는 안내가 나오면 Microsoft의 WebView2 Runtime을 설치하세요.

Mac 노트북 · Apple Silicon터미널
  1. 화면 왼쪽 위의 Apple 메뉴 → 이 Mac에 관하여에서 칩이 M1·M2·M3·M4 등 Apple Silicon인지 확인하세요. Intel Mac용 설치 파일은 제공하지 않습니다.
  2. Spotlight(⌘ + Space)에서 터미널을 열고 아래 한 줄을 붙여 넣으세요.
    curl -fsSL https://raw.githubusercontent.com/jhs512/molip-quest/main/packaging/macos/install.sh | bash
  3. 앱, uv, Python, 수업 패키지를 자동으로 준비한 뒤 앱을 엽니다. 설치가 끝나면 「환경 진단」을 확인하세요. Homebrew를 따로 설치할 필요가 없습니다.

Mac 실기기에서의 수동 검증은 아직 완료되지 않았습니다. DMG로 직접 설치하는 경우의 첫 실행 안내는 릴리즈 문서에서 확인할 수 있습니다.

AI 도구 준비 · Claude Code 또는 Codex CLI

CLI는 터미널에 명령어를 입력해 사용하는 도구입니다. 둘 중 사용할 도구 하나를 설치하세요. Windows는 시작 메뉴에서 「PowerShell」을, Mac은 Spotlight(⌘ + Space)에서 「터미널」을 열면 됩니다. 아래 명령은 한 단계씩 실행하세요.

Claude Code · 설치와 로그인Windows · Mac
  1. 내 운영체제에 맞는 설치 명령을 실행하세요.

    Windows · PowerShell

    irm https://claude.ai/install.ps1 | iex

    Mac · 터미널

    curl -fsSL https://claude.ai/install.sh | bash
  2. 설치가 끝나면 터미널을 닫고 다시 여세요. 실습용 폴더를 만들고, 터미널에서 cd "실습 폴더의 경로"로 이동하세요. 경로는 실제 폴더 위치로 바꿉니다.
  3. 버전을 확인하고 Claude Code를 실행하세요.
    claude --version
claude
    처음 실행할 때 나오는 로그인 안내에서 Claude 구독 계정으로 로그인하는 항목을 선택하세요. 브라우저에서 로그인하고 접근을 승인한 뒤 터미널로 돌아오세요. 폴더 신뢰 여부가 나오면 방금 만든 실습 폴더인지 확인하고 진행하세요.
  4. 로그인 화면이 나오지 않거나 계정을 바꾸려면, 실행 중인 Claude Code 안에서 /login을 입력하세요. 로그인 후 「파이썬의 변수를 간단한 예시로 설명해 줘」라고 질문해 답변을 확인하세요.

Claude Code는 Claude Pro·Max·Team·Enterprise 또는 별도 API 이용 계정이 필요합니다. 무료 Claude 계정만으로는 이용할 수 없습니다. 공식 설치·로그인 안내 ↗

Codex CLI · 설치와 로그인Windows · Mac
  1. 내 운영체제에 맞는 설치 명령을 실행하세요.

    Windows · PowerShell

    powershell -ExecutionPolicy ByPass -c "irm https://chatgpt.com/codex/install.ps1 | iex"

    Mac · 터미널

    curl -fsSL https://chatgpt.com/codex/install.sh | sh
  2. 설치가 끝나면 터미널을 닫고 다시 여세요. 실습용 폴더를 만들고, 터미널에서 cd "실습 폴더의 경로"로 이동하세요. 경로는 실제 폴더 위치로 바꿉니다.
  3. 버전을 확인하고 로그인 명령을 실행하세요.
    codex --version
codex login
    브라우저가 열리면 ChatGPT 계정으로 로그인하고 접근을 승인하세요. 완료 후 터미널로 돌아오세요. 브라우저가 열리지 않으면 codex login --device-auth를 실행하고 표시된 주소에 접속해 일회용 코드를 입력하세요.
  4. 로그인 상태를 확인한 뒤 Codex를 실행하세요.
    codex login status
codex
    처음 설정 화면이 나오면 안내에 따라 진행한 뒤, 「파이썬의 변수를 간단한 예시로 설명해 줘」라고 질문해 답변을 확인하세요.

이 안내는 ChatGPT 계정 로그인 방식입니다. 사용 가능한 모델과 사용량은 계정·요금제에 따라 달라집니다. 공식 설치 안내 ↗ · 공식 로그인 안내 ↗

준비가 끝나면 몰입 퀘스트의 「프롬프트 복사」로 문제를 복사해 실행 중인 CLI에 붙여 넣으세요. 명령어를 찾을 수 없다는 메시지가 나오면 터미널을 다시 열고, 설치 마지막에 표시된 PATH 설정 안내를 확인하세요.
